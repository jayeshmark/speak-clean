Speak like a diplomat.

A diplomat does not change what you mean. A diplomat changes how it lands: acknowledge first, separate the person from the problem, and keep the commitment exactly as you said it. Preview

Hard rule in this preview: no version invents a date, deadline, promise, or deliverable you did not already give. If you did not promise a day, no version will promise one. If you did promise one, that same day is kept, and no other day is added.

Try a tough situation — pick one, then make it yours

Start with a situation you recognise. Tap it, read the 3 diplomatic ways to handle it, and notice how the same words land differently. Then change the boxes to your own story and try again. That is how you learn to think and speak this way, not just copy a line.

Diplomat’s note — what to learn from this

Diplomat’s toolkit used here: acknowledge before answering, separate the person from the problem, focus on the shared interest instead of the position, use soft language like could, would, and it seems, and ask a question instead of giving an order.
